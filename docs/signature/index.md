# :material-draw-pen: Vous allez signer

Avant de signer, vous avez **le droit de lire le bail tranquillement** et de demander tous les documents obligatoires. Un bail signé ne valide **pas** un loyer illégal ni une clause abusive : ils restent contestables après la signature. Mais c'est plus simple de les repérer avant.

## La check-list de signature

- [ ] Le bail suit le **modèle officiel** (bail type) et indique la **surface habitable**
- [ ] En zone tendue : **loyer de référence**, **loyer de référence majoré** et **loyer du précédent locataire** sont indiqués
- [ ] Le loyer respecte l'**encadrement** si votre ville est concernée
- [ ] Le **DPE** est joint (et la fourchette de dépenses d'énergie figure dans le bail)
- [ ] Les **frais d'agence** respectent les plafonds
- [ ] Le **dépôt de garantie** ne dépasse pas 1 mois HC (vide) / 2 mois HC (meublé)
- [ ] Pas de **clause abusive** (prélèvement imposé, assurance imposée, pénalités, interdiction d'animaux…)
- [ ] Vous recevez la **notice d'information** et le **dossier de diagnostic technique**
- [ ] Un état des lieux d'entrée est prévu, **contradictoire** → [Emménager](../emmenager/etat-des-lieux.md)

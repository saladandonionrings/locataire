# 🏠 Locataire — connais tes droits

> Le guide gratuit et collaboratif des **droits du locataire** et des **obligations du bailleur** en France, et **comment se défendre sans payer d'avocat**.

**👉 Lire le guide : https://saladandonionrings.github.io/locataire/**

## Le guide suit votre parcours

| Étape | Ce que vous y trouverez |
|---|---|
| 🔍 [**Vous faites une visite**](docs/visite/index.md) | Frais interdits, arnaques, pièces qu'on n'a pas le droit de vous demander, discrimination, garant et Visale, check-list de visite |
| ✍️ [**Vous allez signer**](docs/signature/index.md) | Bail, clauses abusives, encadrement des loyers, surface, frais d'agence, dépôt de garantie, meublé |
| 🚚 [**Vous allez emménager**](docs/emmenager/index.md) | État des lieux d'entrée (et son complément sous 10 jours), assurance, premiers jours |
| 🛋️ [**Vous êtes locataire**](docs/locataire/index.md) | Révision IRL, quittances, charges, réparations, logement décent et DPE, travaux, vie privée, impayés |
| 🚪 [**Vous partez du logement**](docs/depart/index.md) | Préavis (souvent 1 mois), congé du bailleur, état des lieux de sortie, dépôt de garantie et pénalités |
| ⚖️ [**Se défendre gratuitement**](docs/recours/index.md) | ADIL, conciliation, juge sans avocat, pièges courants, [modèles de lettres](docs/modeles/index.md) |

## Développement local

Le site est construit avec [MkDocs Material](https://squidfunk.github.io/mkdocs-material/).

```bash
pip install -r requirements.txt
mkdocs serve        # http://127.0.0.1:8000
mkdocs build --strict
```

Le site est publié automatiquement sur GitHub Pages à chaque push sur la branche par défaut du dépôt (workflow `.github/workflows/pages.yml`).

> **Première mise en ligne** : dans *Settings → Pages* du dépôt, choisir **Source : GitHub Actions**.
